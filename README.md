Java-Practical-Assignment-1

This repository contains my Java Programming Practical Assignment.
It includes 10 programs covering basic Java concepts such as variables, data types, operators, conditional statements, loops, arrays, and a mini project.

📚 List of Practicals

Q1. Identifier Naming Practice

Write a Java program that declares variables for a student’s name, roll number, and marks in three subjects. Assign values and print them. Ensure all variable names follow Java identifier rules.

Concepts: Variables, Identifiers, Data Types, Output

⸻

Q2. Data Type Conversion

Write a Java program that stores an integer value for temperature in Celsius and converts it to Fahrenheit using the formula:

F = (C × 9/5) + 32

Display both Celsius and Fahrenheit values.

Concepts: Data Types, Type Conversion, Arithmetic Operators

⸻

Q3. Arithmetic Operations

Accept two integers from the user and perform:

* Addition
* Subtraction
* Multiplication
* Division
* Modulus

Display the result of each operation.

Concepts: User Input, Arithmetic Operators

⸻

Q4. Logical Operators – Eligibility Check

Write a Java program to check whether a person is eligible to vote.

Input:

* Age
* Citizenship status (true or false)

Use logical operators such as && and || to determine eligibility.

Concepts: Logical Operators, Boolean Values, Conditional Statements

⸻

Q5. Control Statement – Simple Calculator

Write a Java program that takes two numbers and an operator symbol (+, -, *, /) from the user.

Use if-else statements to perform the appropriate operation.

Concepts: User Input, Operators, If-Else Statements

⸻

Q6. Loop – Multiplication Table

Write a Java program that asks the user for a number and prints its multiplication table from 1 to 10 using a for loop.

Concepts: For Loop, Iteration

⸻

Q7. Loop with Conditional – Sum of Even Numbers

Write a Java program that uses a while loop to find the sum of all even numbers between 1 and 50.

Concepts: While Loop, Conditional Statements, Arithmetic Operations

⸻

Q8. Arrays – Store and Print Marks

Write a Java program that reads marks of 5 students into an integer array and prints each student’s marks.

Concepts: Arrays, User Input, Loops

⸻

Q9. Arrays and Loops – Find Maximum

Write a Java program to read 10 integers into an array and find the maximum value using a loop.

Concepts: Arrays, Loops, Comparison

⸻

Q10. Mini Project – Average and Grade

Write a Java program that reads marks of 5 subjects into an array and calculates the average marks.

The program assigns grades using if-else statements:

Average Marks	Grade
>= 90	A
>= 75	B
>= 50	C
< 50	Fail

Concepts: Arrays, Loops, Average Calculation, If-Else Statements

⸻
